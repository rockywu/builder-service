## 自动验收范围

- 本地真实 Git HTTP 仓库与独立源码副本，固定完整提交、分支与入队配置快照；真实 Bash、Node.js、`npm ci --offline`、`npm run build` 执行。
- 上限 2 时提交 5 个任务，实际两个占槽、FIFO 补位；调低不中断在执行任务，调高立即补位。
- 失败、进程超时、停止确认、环境变量隔离、路径穿越与符号链接拒绝、产物字节和 SHA-256。
- 匿名下载与内部字段白名单、CSRF、管理权限、同名用户重建不继承历史任务操作权、密码重置撤销会话。
- 测试状态 revision 冲突、六版本服务端筛选及分页、版本删除后文件和记录读回。
- 图标解码与像素限制；旧孤立图标有界清理与在用图标保留。
- 备份目录失败后解除写入门禁；数据库和文件恢复到新目录；产物已写入而版本尚未提交的恢复；损坏已发布产物退出公开列表。
- 真实服务 SIGKILL 后重启，先终止遗留进程再补位；删除与领取竞争、文件读取占用时清理失败可重试、重启续清理、删除后迟到幂等请求拒绝。

测试只使用任务临时目录和独占进程，没有连接真实业务仓库或生产数据库。

## 保留的实际限制

本机执行仅用于受信任仓库，脚本具备服务账号的本机权限，不构成操作系统级隔离。Docker 运行、服务器网络出口、私有仓库受限凭据、目标 Linux 工具链及生产恢复仍须部署时单独验收。运行与恢复步骤见 [runtime.md](./runtime.md)。
