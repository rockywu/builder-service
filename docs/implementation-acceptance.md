## SSH 后端补齐（2026-11-12）

源码包含版本 4 迁移、加密私钥存储、8 个密钥/主机接口、项目绑定、队列快照和远端 Git 凭据注入。项目引用继续使用 JSON payload，删除引用与密钥在同一事务处理，接口只返回公开密钥信息。现有 Vue 模板和样式未改；前端仅同步任务类型和主机解析规则。

本轮使用 `gpt-6.1-sol / high` 测试代理，独立临时数据库与本机高端口 SSH 服务。构建及类型检查通过；`test/ssh.test.mjs` 7/7、认证与平台 15/15 通过。日志与版本 SHA-256 在 `var/validation/ssh/round3-*.log`、`round3-versions.json`，失败夹具修正前的日志另行保留，不能作为当前结论。

- 真实 `ssh-keygen` 生成与 OpenSSH/PEM 导入、与系统指纹一致；拒绝带口令、超限和 RSA 小于 2048 位的私钥。
- AES-GCM 随机 nonce、篡改拒绝、主密钥缺失/错误、管理员与 CSRF 边界、私钥不出现在接口响应和审计中。
- 生成密钥 → 本地 SSH 只读授权 → 信任主机 → 项目绑定 → 拉取固定 SHA → 入队 → Bash 构建 → 产物内容核实；两把受限密钥同时构建各自产物。
- 主机公钥变化、授权被撤销、信任被移除、已删除快照密钥均明确失败；成功使用更新时间；凭据目录 0700、文件 0600。
- 失败/取消/超时清理，启动残留清理，构建环境无主密钥或临时凭据路径；原始私钥不在构建日志中。
- Docker 只读挂载与构建阶段无凭据挂载已验证**命令参数**，使用本地替身记录参数，不能视为真实容器验收。
- 版本 3 迁移后旧项目密钥缺省 null；备份/离线恢复保存加密私钥，原主密钥可解密，错误主密钥拒绝；备份不含临时凭据。

扫描 API 拒绝私网、环回、保留和元数据地址；正常 `ssh-keyscan` 使用真实本地夹具在执行器层验证，未扫描外部主机。目标 Git 专用网络、防火墙、真实 Docker 私钥隔离与生产恢复尚未验收。本机模式只适用于受信任脚本，同账号宿主权限仍可跨目录读取，不能当作容器隔离。

远端 CI、PR/合并和服务器部署本轮未执行。启用密钥功能前须配置独立保管的 `BUILDER_SECRET_KEY`，见运行文档。

本轮 Chrome 页面实际联调通过：设置页生成密钥、重命名；项目选择 SSH 密钥后保存、重新打开仍正确回填；未信任主机提示；HTTPS 地址隐藏密钥选择并显示匿名拉取说明；删除密钥时展示绑定项目影响，删除后密钥列表为空。普通用户浏览器提示未另建账号实测，其 API 权限拒绝已由专项测试覆盖。截图见本次 CUA 工具输出，工具未返回本地图片路径。
